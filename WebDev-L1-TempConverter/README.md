# Temperature Converter Web App

**OASIS INFOBYTE Web Development and Designing Internship (Level 1 — Task 3)**

## Overview
An interactive temperature converter web application built with **HTML5**, **CSS3**, and **JavaScript** that converts values between Celsius (°C), Fahrenheit (°F), and Kelvin (K) with input validation.

## Features
- Numeric input validation with clear inline error feedback
- Support for Celsius, Fahrenheit, and Kelvin conversions
- Simultaneous formatted display across all three temperature scales
- One-click Reset button and mobile-friendly responsive layout
