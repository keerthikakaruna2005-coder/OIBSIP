# LeafLine Studio — Landing Page (Oasis Infobyte Level 1, Task 1)

A static, responsive landing page for **LeafLine Studio**, a concept brand focused on sustainable study and desk essentials.

## Features Implemented
- Fixed top navigation bar with smooth section links (`Features`, `About`, `Contact`)
- Hero section with value proposition, subheadline, and call-to-action button
- Product features grid (`Recycled Cork Desk Mat`, `Refillable Stone-Paper Notebook`, `Eye-Care LED Desk Lamp`)
- Brand story and sustainability commitments section
- Footer with placeholder contact and social links
- Responsive layout for desktop, tablet, and mobile screens using CSS Flexbox and Grid

## Tech Stack
- HTML5
- CSS3

## How to Run
1. Open `index.html` in any modern web browser (Chrome, Edge, Firefox).
